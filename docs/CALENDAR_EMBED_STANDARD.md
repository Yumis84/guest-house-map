# Стандарт календарного iframe для всех гостевых домов

Утверждено 21.10.2026 после проверки календаря на сайте «У Степана».

Обязательно для генератора кода в личном кабинете:
1. Выдавать iframe и JS-обработчик высоты вместе, не один iframe.
2. Начальная резервная высота 1100px, scrolling="no", overflow:hidden.
3. Виджет сообщает родительскому сайту реальную высоту через postMessage с типом guest-house-calendar:resize. Добавляет 24px запаса.
4. Высота пересчитывается после переключения месяца, ResizeObserver, загрузки шрифтов и изменения размеров окна.
5. Родитель проверяет event.origin (https://yumis84.github.io), event.source (конкретный iframe.contentWindow), Number.isFinite(data.height) и пределы 350–3000px.
6. Должны помещаться месяцы с 4, 5 и 6 рядами недель, мобильные устройства и крупные шрифты. Без внутренней вертикальной прокрутки.
7. При нескольких виджетах на странице генерировать уникальный id iframe.
8. Каждый код привязан к своему property ID. Никаких личных данных гостей; неподтвержденные даты не помечать свободными.

Эталон: https://saned039.github.io/stepan/#availability-calendar
Реализация в репозитории: widget/calendar.html; обработчик родительской страницы: Saned039/stepan index.html.

ВАЖНО: текущий widget/calendar.html пока содержит жестко заданный ID дома «У Степана». До выдачи кодов другим владельцам необходимо реализовать безопасный параметр property, публичный источник подтвержденных занятых дат и сам генератор в личном кабинете. Этот документ фиксирует обязательный стандарт, но не заявляет, что генератор уже готов.
