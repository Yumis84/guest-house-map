# Guest House Map

Мобильный прототип каталога гостевых домов Краснолесья и Роминтенской пущи.

## Сейчас

- карта гостевых домов;
- каталог и фильтры;
- избранное;
- карточки объектов;
- форма запроса на бронирование;
- экран AI-помощника, подготовленный для подключения n8n.

## Источник прототипа

Перенесено из ветки `guest-house-prototype` репозитория `Yumis84/sauna-map-prototype` в отдельный репозиторий, чтобы развитие гостевых домов не затрагивало рабочий проект «Пар-Гид».

## n8n

Production webhook гостевого workflow пока намеренно не прописан. После получения рабочего URL AI-чат будет подключён отдельно.
