# Guest House Map

Мобильный сервис-каталог гостевых домов Краснолесья и Роминтенской пущи.

> **Статус:** текущая рабочая версия зафиксирована как финальная на 16.08.2026. Дальнейшие изменения — только в рамках новой согласованной итерации.

## Что работает

- карта гостевых домов с реальными координатами;
- нижняя карусель карточек, синхронизированная с картой;
- подсветка активной метки при листании карточек;
- каталог, поиск и фильтры;
- геолокация пользователя «Вы здесь»;
- избранное с синхронизированными сердечками;
- карточки объектов со свайпом вниз для закрытия;
- свайп влево/вправо между объектами с синхронизацией списка на фоне;
- реальные фотогалереи объектов;
- увеличенная фотогалерея без обрезки изображений;
- форма запроса на бронирование через n8n;
- рабочий компактный AI-помощник через n8n Chat Trigger.

## Активный frontend-слой

Основные рабочие улучшения загружаются из `guest-houses.js`: `guest-n8n-v1.js`, `guest-chat-compact-v3.js`, `guest-photos-v4.js`, `guest-final-ux-v5.js`, `guest-map-fix-v6.js`, `guest-gallery-large-v7.js`, `guest-sauna-swipe-v11.js`, `guest-final-parity-v12.js` и `guest-marker-dom-sync-v14.js`.

Экспериментальные gesture/marker-версии, которые были заменены рабочими реализациями, удалены из репозитория.

## Архитектура

Frontend — отдельный репозиторий. Web Chat и форма бронирования подключены к production workflows гостевых домов в n8n. Telegram остаётся вторым каналом того же backend, а Google Sheets — единым источником каталога и бронирований.

## Фото

Фотогалереи подключены через `guest-photos-v4.js`. Для каждого объекта хранится источник фото; при недоступности изображения интерфейс возвращает нейтральную заглушку. `guest-gallery-large-v7.js` поднимает карточку почти до верха экрана и показывает исходные фото целиком через `object-fit: contain`.
