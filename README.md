# Guest House Map

Мобильный прототип каталога гостевых домов Краснолесья и Роминтенской пущи.

## Сейчас

- карта гостевых домов;
- каталог и фильтры;
- избранное;
- карточки объектов;
- реальные фотогалереи объектов;
- увеличенная фотогалерея без обрезки изображений;
- форма запроса на бронирование через n8n;
- рабочий компактный AI-помощник через n8n Chat Trigger.

## Источник прототипа

Перенесено из ветки `guest-house-prototype` репозитория `Yumis84/sauna-map-prototype` в отдельный репозиторий, чтобы развитие гостевых домов не затрагивало рабочий проект «Пар-Гид».

## n8n

Web Chat и форма бронирования подключены к production workflows гостевых домов. Telegram-ветка остаётся отдельным каналом того же backend.

## Фото

Фотогалереи подключены через `guest-photos-v4.js`. Для каждого объекта хранится источник фото; при недоступности изображения интерфейс автоматически возвращает нейтральную заглушку. Дополнительный layout `guest-gallery-large-v7.js` поднимает карточку почти до верха экрана и показывает исходные фото целиком через `object-fit: contain`.
